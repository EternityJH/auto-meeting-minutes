歡迎使用！本指南將帶領您一步步設定您的 Gemini API Key 與架設自動發送電子郵件的 Webhook 系統。

如何取得 Gemini API Key

  • 1
    前往 Google AI Studio 網站
    打開瀏覽器，前往 Google AI Studio (aistudio.google.com) 並使用您的 Google 帳號登入。
  • 2
    建立 API 金鑰 (Create API Key)
    在頁面左上角，點擊藍色的 「Get API key (取得 API 金鑰)」 按鈕，接著點擊 「Create API Key」。
  • 3
    選擇專案並生成
    選擇 「Create API key in new project (在新專案中建立)」。系統在生成完成後會顯示一串長金鑰。
  • 4
    複製並儲存至擴充功能
    點擊 「Copy」 複製該金鑰。返回本擴充功能的「設定」分頁，將其貼上到 Gemini API Key 輸入框中，最後點擊「儲存設定」。
💡
安全提示：您的 API Key 將會 100% 儲存在您自己本機電腦的瀏覽器安全磁區中，擴充功能絕對不會將您的 Key 傳送給任何第三方。
💰
💡 實用提醒：如何確認我的 API Key 是「免費版」還是「付費計價版」？
  • 預設為免費方案 (Free Tier)：當您剛建立 Google AI Studio 帳號並生成金鑰時，系統預設是完全免費的，每天有免費的使用額度限制，您不需要綁定任何信用卡。
  • 資料隱私安全差異：
    • 在免費方案下，輸入的會議逐字稿內容可能會被 Google 作為模型訓練或產品改進用途。
    • 若切換至按量計費方案 (Pay-as-you-go)，您的會議資料將會 100% 保密，Google 承諾絕對不會使用付費用戶的資料來訓練模型。如果您非常在意會議隱私，建議在 Google AI Studio 中開啟計費。
  • 如何查看目前狀態：登入 Google AI Studio 後，點擊左側選單的 「Billing (計費)」：
    • 若顯示「Pay-as-you-go is disabled / Set up billing」，代表為免費方案（完全免費，無信用卡扣款風險）。
    • 若您已綁定 Google Cloud Billing 專案並啟用付款，則為付費方案。

如何利用 Google Apps Script 架設自動寄信 Webhook

您可以免費使用 Google Apps Script 將會議記錄直接自動寄送到多個信箱。此方式非常安全，完全不需要購買任何付費伺服器！

  • 1
    建立 Google Apps Script
    前往 Google Apps Script 官網 (script.google.com)，使用您的 Google 帳號登入後，點擊左上角的 「新增專案」。
  • 2
    貼上整合程式碼
    清空編輯器中預設的程式碼，複製並貼上底下的程式碼：
    Google Apps Script 接收端程式碼 
    function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    
    // 讀取收件人
    var toEmails = data.targetEmail;
    
    // 💡 如果擴充功能中沒有設定收件人，則直接結束不寄信
    if (!toEmails || toEmails.trim() === "") {
      return ContentService.createTextOutput(JSON.stringify({status: "success", message: "No email provided, skipping."}))
        .setMimeType(ContentService.MimeType.JSON);
    }
    
    // 💡 優先使用 AI 整理出來的會議主旨，若無則回退到 Meet 網頁標題
    var aiSubject = data.aiSubject || data.title;
    var subject = "【自動會議紀錄】" + aiSubject;
    
    // 優先使用 summaryHtml (如果存在)，否則回退到 summaryPlainText 或 summary
    var htmlContent = data.summaryHtml || "";
    var plainTextContent = data.summaryPlainText || data.summary || "";
    
    // 建立郵件內文
    var dateStr = new Date(data.startTime).toLocaleString('zh-TW');
    
    // 組合 HTML 格式的精美信件內容
    var emailHtmlBody = 
      "<div style='font-family: system-ui, -apple-system, BlinkMacSystemFont, Helvetica, Arial, sans-serif; max-width: 850px; margin: 0 auto; line-height: 1.6; color: #1f2937; padding: 20px;'>" +
        "<h2 style='color: #4f46e5; border-bottom: 2px solid #e5e7eb; padding-bottom: 12px; margin-bottom: 20px; font-size: 22px;'>會議主題：" + data.title + "</h2>" +
        "<div style='background-color: #f3f4f6; padding: 12px 18px; border-radius: 6px; font-size: 13.5px; color: #4b5563; margin-bottom: 25px;'>" +
          "<strong>會議時間：</strong>" + dateStr + "<br>" +
          "<strong>會議連結：</strong><a href='" + data.url + "' style='color: #2563eb; text-decoration: none;'>" + data.url + "</a>" +
        "</div>" +
        "<div style='font-size: 15px; color: #1f2937;'>" + 
          htmlContent + 
        "</div>" +
      "</div>";

    // 發送 HTML 郵件
    MailApp.sendEmail({
      to: toEmails,
      subject: subject,
      htmlBody: emailHtmlBody,
      body: "您的瀏覽器不支援 HTML 郵件。以下為純文字備份：\n\n" + plainTextContent
    });
    
    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: error.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  • 3
    部署為網頁應用程式 (Deploy)
    1. 點擊編輯器右上角的 「部署」 -> 「新增部署」。
    2. 點擊左邊齒輪圖示，選取 「網頁應用程式」。
    3. 設定部署細節：
    • 將專案執行身分設為：「我」 (您的帳號)
    • 將誰有權限存取設為：「所有人」 (Anyone) (這步非常重要，擴充功能才能成功發送資料進去！)
    4. 點擊下方的 「部署」 按鈕。
  • 4
    授權權限
    首次部署時，系統會要求您授權「傳送電子郵件」的權限：點擊 「授權存取」，選取您的 Google 帳號，點擊 「進階」，然後選取 「前往「未命名專案」(安全)」，最後點選 「允許」。
  • 5
    複製網頁應用程式網址 (Webhook URL)
    部署完成後，畫面上會顯示一串 「網頁應用程式網址」 (通常以 `https://script.google.com/macros/s/...` 開頭)。複製此網址，貼回到擴充功能設定中的 Webhook URL，並儲存即可！
📢
多收件人功能：您可以在擴充功能設定中，將「收件人 Email」設定為多個地址（用半形逗號隔開）。當自動整理完成時，此指令會一次將精美的 HTML 信件寄送給清單中的所有人！
